The Users page allows you to manage two types of users: Admin Users who access the Benji platform, and Members who have connected their loyalty program accounts to participate in your partnerships.

![Users](/images/users.png)

### Admin Users

Each admin user is assigned one or more roles that control what they can access and action within Pilot. All users have view-only access across the account by default. Roles add the ability to take actions on top of that baseline.

The following roles are available:

- **Admin**: Full access to all features and settings in Pilot, including user management. Admin must be assigned on its own.
- **Campaign Manager**: Create new partnerships and campaigns, and access the marketing section.
- **Support**: Reverse transactions, and block or unlink members.
- **Developer**: Access the developer section, manage API keys, and configure webhooks and integrations.
- **Member**: View-only access across the entire account. Member must be assigned on its own and is selected by default when inviting a new user.

A user can hold more than one role, with two restrictions: Admin must be assigned alone, Member must be assigned alone, and Campaign Manager, Support, and Developer can be combined in any mix. At least one role must always be assigned. Only Admins can assign or change roles, and changes take effect immediately.

**Invite New User**

Click the Invite New User button to send an invitation to a new administrator. They will receive an email with instructions to set up their account. Select a role for the user during the invitation flow.

**Admin User Actions**

- **Resend Invite**: Send a new invitation email to users with Invited status
- **Edit**: Modify the user's name
- **Delete**: Remove the user from your account

### Collaborators

Collaborators are users invited to access a specific partnership. Collaborator status grants edit access on that partnership beyond the view-only access every user already has.

All users at either company automatically have view-only access to the partnerships their company is connected to. On the partnerships list, each partnership shows a Collaborator badge if the user has edit access, or a View only badge if they do not. A view-only user can open the partnership and see all of its content, but the actions are disabled until they are added as a collaborator.

Collaborators are invited from the partnership page. Each collaborator is assigned one of the following roles:

- **Owner**: Full control over the partnership, including managing all other collaborators and transferring ownership. There is only one Owner per partnership, and the creator of the partnership is the Owner by default.
- **Admin**: Edit anything in the partnership and manage collaborators, except the Owner. Cannot transfer ownership.
- **Campaign Manager**: Create, edit, and launch campaigns. Cannot manage collaborators.
- **Marketing**: Edit partnership components and landing pages. Cannot create or edit campaigns.

Assigning the Owner role to another collaborator transfers ownership. The current Owner becomes an Admin, and the change requires an explicit confirmation.

**Collaborator Actions**

- **Edit**: Modify the collaborator's name or role
- **Delete**: Remove the collaborator's access to the partnership

### Members

The Members tab is available to Admin users and displays all loyalty program members who have connected their accounts through your partnerships.

**Member Actions**

- **View**: Open the detailed member profile showing transaction history and connection details
- **Unlink**: Disconnect the member's account from a specific partner (typically used for troubleshooting)
- **Block**: Prevent the member from participating in campaigns

### Member Profile

Clicking View on a member opens their detailed profile, which includes:

**Summary Metrics**

- **Transactions**: Total number of transactions
- **Points Earned**: Total points earned across all partnerships
- **Points Redeemed**: Total points redeemed across all partnerships

**User Details**

Displays the member's basic information including name, loyalty program member number, status, and email.

**Custom Attributes**

Displays the member's custom attribute values that are visible to this partner. Values are populated through the Benji API. You can manually edit a value directly on the profile, mainly for support cases. A manually edited value is marked as overridden and is no longer updated by API refreshes until the override is cleared. The profile shows whether each value is synced from the API or manually overridden.

**Connections**

Shows all partnerships the member is connected to, including the partner name, connection date, and member ID for each partner.

**Transactions Tab**

View the member's complete transaction history across all partnerships.
